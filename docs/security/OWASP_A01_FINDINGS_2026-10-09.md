# OWASP A01 (Broken Access Control) Findings, 2026-10-09 (--deep, focused slice)

Category: owasp-web / A01. Maker: owasp-web-checker. Cross-references SEMGREP_FINDINGS_2026-10-09.md and OWASP_WEB_FINDINGS_2026-10-09.md (neither edited).

Method: a locally built hub (`go build ./cmd/kryptkeeper`) ran on a free 127.0.0.1 port with `MULTI_TENANCY=true`, using the env from tests/live/plugins/run.sh. The bootstrap token created tenant-a and tenant-b, plus API keys adminA (pki-admin), opA and opA2 (pki-operator), viewA (pki-viewer) and mcpA (mcp-agent) in tenant-a, and adminB in tenant-b. A default-tenant root CA, a template, a leaf cert and a credential were also created. The hub and its temp dir were removed afterwards. One temporary Go test (`internal/bootstrap/zz_a01_race_tmp_test.go`) was run and then deleted. No product code was changed.

## REAL findings

| A01-001 | CRITICAL (MT on) | internal/bootstrap/handlers_auth.go:317-335 | Any tenant pki-admin can mint API keys in **any** tenant. `POST /api/v1/api-keys` checks only `isAdminRole(principal.Role)` and then passes the caller-supplied `req.Tenant` straight to `CreateAPIKey`. ## Verified not vulnerable (A01 scope item 1 and 3)

- **Path normalization.** Viewer POSTs to `/api/v1/cas` through `..%2F`, `%2f`, `auth%2F..`, `agent/%2e%2e`, `//`, `/./`, a trailing `/`, `/API`, `;x=1`, `%2F` and `..;/` were tested. Every one returned 403 from the gate, 405 or 307. None reached the handler. The gate fails closed: an unmatched path is treated as admin-only.
- **Method sweep.** Every registered `/api/v1/**` and `/scim/v2` route (146) was called with FOO, OPTIONS and HEAD as viewA. None returned 2xx or 500. Handlers check `r.Method` explicitly, and no GET handler was found that mutates state (SEMGREP-008 closed as not exploitable).
- **Routes outside /api/v1.** ACME, EST, SCEP, CMP, WSTEP, XCEP, OCSP, CRL and /metrics are protocol endpoints with their own authentication (EAB, shared secret, CSR proof). SCIM requires its own bearer token, and the SCIM client can set any role, including pki-admin. That is by design, because the IdP is trusted (informational).
- **Self-authenticating routes.** `/api/v1/auth/**` has no prefix handler, only the named routes. `/api/v1/agent/**` requires enrolment secrets unless `KRYPTKEEPER_AGENT_OPEN_REGISTRATION=true`, which is opt-in and logs a warning (SEMGREP-011 confirmed LOW, not default).
- **Approval queue.** Proposer ≠ approver is enforced (handlers_pending_actions.go:164, handlers_approvals.go:219, pqc_wave_execute.go:180). `canApproveActions` rejects mcp-agent first. The executor reads params from the stored action, so the approver cannot swap them. Delivery-plugin enable goes through the same queue (delivery_plugins.go:316).
- **SEMGREP-010.** The SPIFFE `key_pem` is returned only to a caller that holds certificate.issue, and the key is server-generated by design. No `Cache-Control: no-store` is set on these responses (LOW hardening).
- **SEMGREP-009.** Closed by the normalization tests above.

## Confidence

A01: 7/10. The write gate, normalization, methods and approval queue are covered at high confidence. Tenancy was probed live across about 25 list and get endpoints. Not covered: per-object IDOR on update/delete for connectors, inventory-sources and nhi, and SCIM/MCP transport internals.
