Issue SSH certificates

Sign SSH user and host certificates.

As pki-admin

  1. Step 1

    Open /ssh-certificates

  2. Step 2

    Click Copy CA public key

  3. Step 3

    Fill Key ID with "alice@acme.test"

  4. Step 4

    Fill Principals with "deploy"

  5. Step 5

    Paste the Public key (authorized_keys line)

  6. Step 6

    Fill TTL hours with "8"

  7. Step 7

    Click Issue certificate
