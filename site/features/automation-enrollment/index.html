Feature

Automation and enrollment

Speaks the protocols your clients already use.

Servers renew over ACME, devices enroll over SCEP, EST or CMP, and agents or agentless targets install certificates where they are used. Rollouts go to a canary first, and failures wait in one queue.

How it works

  1. Set up ACME for a server

    Create a provisioner and EAB key, then point an ACME client at it.

    10 steps

  2. Enroll devices with SCEP, EST or CMP

    Set up EST and CMP enrollment, then create a SCEP challenge for a device.

    12 steps

  3. Enroll a satellite agent

    Enroll an agent that installs certificates on its host.

    7 steps

  4. Add an agentless target

    Start adding an SSH or WinRM target with nothing installed and see what the wizard needs before it can finish.

    8 steps

  5. Create a rollout group for a cluster

    Group a cluster's nodes, set a rollout window and save the group.

    9 steps

  6. Watch the failed-renewal queue

    See every renewal that needs a person, in one place.

    3 steps

  7. Push a CA to your hosts' trust stores

    Propose a CA bundle for chosen agents, have a second person approve it, and read the per-host result.

    9 steps
