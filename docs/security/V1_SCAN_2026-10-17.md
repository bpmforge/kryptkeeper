## Accepted residuals (recorded, not fixed)

- SCIM: custom roles are not inspected and `pki-operator` (an approver role) stays assignable (D-204).
- ACME http-01 still reveals "could not fetch" vs "bad status" — inherent to the protocol.
- Audit transparency Merkle log is global; `/api/v1/meta` unauthenticated; `/metrics` open unless a bearer is configured.
- Refresh token is held in sessionStorage (no XSS sink found in the UI); moving it to an httpOnly cookie is a follow-up.
- `docker-compose.override.yml` defaults `POSTGRES_PASSWORD` to `changeme`; the port is not published outside the compose network.
- Base images pinned by tag, not digest.

## Disconnected features found by dead-code analysis (follow-ups)

- **Retired CA key destruction never runs** (`RetiredKeyGraceFromEnv`, `RetireRotatedKeys`): docs/ops/KEY_ROTATION.md promises destruction after the grace period. Wiring it destroys key material, so it needs an owner decision.
- NHI authorizer not wired (D-150, known).
- Audit archive restore has no handler or CLI.
- Agent HTTP-01 port preflight never enabled (W24-14 "DECISION NEEDED").
- Scanner-provider requeue drops custom ports.
- `logging.WithTenant` unused, so tenant never appears in structured logs.
- Agent/NHI/SPIFFE tables need a tenant column to lift D-203.
