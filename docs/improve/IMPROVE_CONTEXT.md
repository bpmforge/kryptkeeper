# Improvement Context

## Mode
Mode 4 — Improve

## Scope
Full app review: UX/UI, frontend consistency, code quality, performance, and process/doc alignment.

## Prompted vision
The product should better support companies managing crypto inventory and automating PKI/crypto operations. The interface should move from summary dashboard toward guided operational workflows: identify urgency, drill into detail, act, and audit.

## What the user wants
- Validate the current docs and process.
- Review the app with the updated agent workflow.
- Find UX/UI/frontend gaps against the product vision.
- Surface improvements for enterprise/business use.

## Constraints
- No users yet; this is still an early-stage build.
- Nothing is off-limits.
- Willing to make large changes if they improve fit and usability.

## Desired direction
- Industrial, utilitarian, risk-first, task-oriented.
- Better inventory management and automation support.
- Stronger drill-down, actionability, and enterprise readiness.
