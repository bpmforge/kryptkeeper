Try Kryptkeeper in five minutes

One command starts a hub with sample data, so the first screen you see is a working estate instead of an empty console. Everything it creates is labelled demo=true, and one command removes it.

1. Start it

You need Docker (or Podman) with Compose. The first run pulls five small images; after that it starts in about ten seconds.

git clone https://github.com/bpmforge/kryptkeeper.git
cd kryptkeeper
docker compose -f deploy/try/compose.yaml up

This starts the hub on PostgreSQL, the web console, two small TLS servers for the hub to discover, and a one-shot seeder that fills the hub through its public API.

2. Sign in

Open http://localhost:3000 and sign in as admin@demo.test with the password kryptkeeper-demo. You land on a dashboard with two CAs, about 40 certificates (active, expiring within two weeks, expired, revoked, and one with a weak 1024-bit RSA key and a SHA-1 signature), plus the two certificates the hub found on the demo servers. A banner marks it all as demo data.

A good first tour: Certificates to filter by state, Discovery for the two servers that were scanned, and Compliance to see which certificates are not quantum-safe.

3. Reset it

As an admin, choose Reset demo data in the banner. That revokes the certificates labelled demo=true and clears the banner. To fill the hub again:

docker compose -f deploy/try/compose.yaml run --rm seeder

4. Remove it

docker compose -f deploy/try/compose.yaml down -v

That deletes the containers and every volume, including the demo CA keys.

This is a demo, not a deployment

The sign-in, the API token and the signing secret are published in the compose file, so every port is bound to localhost and the hub says so by reporting the trial environment. The seeder refuses any hub that reports production, and any hub that already holds certificates that are not demo data.

On Kubernetes, helm install kk charts/kryptkeeper -f charts/kryptkeeper/values-demo.yaml does the same on a throwaway cluster. For a real install, start from the quick start and the deployment guide.
