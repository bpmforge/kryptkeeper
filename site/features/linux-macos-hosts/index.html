Feature

Linux and macOS hosts

Certificates that land on the host and renew themselves.

Run the lightweight agent on Linux and macOS, or manage hardened hosts agentlessly over SSH. Renewal policy is set per target, rollouts go canary first, and anything that fails lands in one queue.
