Enroll a satellite agent

Enroll an agent that installs certificates on its host.

As pki-admin

  1. Step 1

    Open /targets/setup

  2. Step 2

    Fill Agent name with "web-02.acme.test"

  3. Step 3

    Select "Linux" in Host type

  4. Step 4

    Click Generate token

  5. Step 5

    Locate Revoke token datacenter-a

  6. Step 6

    Open /agents

  7. Step 7

    Locate Install an Agent
