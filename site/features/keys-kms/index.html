Feature

Keys and KMS

Keys in software, HSM or cloud KMS, with dual control for the root.

Generate, back up, import and rotate keys. Root keys can be escrowed and recovered only under dual control, and cloud KMS keys show up in one inventory.

How it works

  1. Generate, back up and rotate keys

    Run the key lifecycle from the console.

    9 steps

  2. Escrow and recover a root key

    Open the escrow, recover and BYOK-export actions for a root key, which need two people to complete.

    8 steps

  3. Review cloud KMS keys

    See the keys held in your cloud KMS.

    1 step
