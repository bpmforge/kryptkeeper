Create a certificate template

Name the template, set its lifetime, key usage and algorithms, then create it.

As pki-admin

  1. Step 1

    Open /templates

  2. Step 2

    Click New template

  3. Step 3

    Fill Name (identifier) with "web-server-30d"

  4. Step 4

    Fill Validity period with "30d"

  5. Step 5

    Fill Extended key usage with "serverAuth"

  6. Step 6

    Fill Allowed algorithms with "ECDSA-P256"

  7. Step 7

    The filled New template dialog

  8. Step 8

    Click Create
