Open-source PKI · Apache 2.0

Run your own certificate authority, and stop finding out about expiry from an outage.

Kryptkeeper is a self-hosted CA and certificate lifecycle platform. It issues over ACME, EST, SCEP, CMP and Windows autoenrollment, finds the certificates you didn't know about, and renews and installs them without a person in the loop.

Extend it

Build your own integrations

Delivery plugins are WASM modules with three functions: Validate, Push and Rollback. They run sandboxed, declare the capabilities they need, and come in signed tiers (first-party, verified, community); a new plugin starts disabled until an admin turns it on. Everything the console does is also in the REST API, with SDKs for Go, Python and TypeScript, a Terraform provider and an MCP server.

Quick start

Running in a few minutes

Docker Compose with SQLite. Set two different secrets in .env; the hub creates its root CA on first boot. The dashboard comes up on port 3000 and the API on 8080.

git clone https://github.com/bpmforge/kryptkeeper.git
cd kryptkeeper
cp env.example .env
# set APP_BOOTSTRAP_TOKEN and KRYPTKEEPER_KEYSTORE_PASSPHRASE
# (different values): openssl rand -hex 32
docker compose up -d

Helm, Terraform, binary, deb/rpm and air-gapped installs are in the deployment guide. Homebrew (Apple Silicon) and the Windows agent MSI are in the packaging guide.

Verify the release

Signed without a key to leak

Checksums and images are signed keyless with Sigstore cosign, bound to the GitHub release workflow. There is no long-lived signing key to fetch or trust.

cosign verify ghcr.io/bpmforge/kryptkeeper:1.0.0 \
  --certificate-identity \
  "https://github.com/bpmforge/kryptkeeper/.github/workflows/release.yml@refs/tags/v1.0.0" \
  --certificate-oidc-issuer \
  "https://token.actions.githubusercontent.com"

Images: ghcr.io/bpmforge/kryptkeeper, -agent, -certmanager, -mcp for linux/amd64 and linux/arm64.

v1.0.0 status

What's proven, what isn't yet

Each area is labelled by how it was tested on the 1.0.0 lab pass: proven means run end to end against real clients and servers, not only unit tests.

Proven in the lab

  • ACME, EST, SCEP, CMP, OCSP and CRL against real clients, plus renewal from Let's Encrypt (staging) over DNS-01
  • Windows Group Policy autoenrollment and renewal on Windows 11 and Server 2022
  • WinRM discovery, IIS install with rollback, and the Windows agent MSI
  • Unattended renewal and install on nginx, Apache, HAProxy and Tomcat, agent or agentless
  • Discovery with fingerprinting, privileged agentless Linux scans and inventory sync
  • CA hierarchy, offline root, key ceremony, escrow and PKCS#11 with dual control
  • Post-quantum ML-DSA certificates against OpenSSL 3.5, and code signing with cosign
  • SSO, SPIFFE, approvals, MCP, SIEM, ITSM and notifications
  • Kubernetes with cert-manager, Helm HA and air-gapped installs; SQLite and PostgreSQL

Proven against emulators or stand-ins

  • F5 BIG-IP and Citrix delivery (mock appliance)
  • AWS KMS, Azure Key Vault and Google Cloud KMS (emulators)
  • ServiceNow, Jira Cloud, Slack and PagerDuty (local stand-ins)
  • Delivery to AWS, Azure and Google Cloud certificate services (Vault leg proven)

Not yet

  • Install modes for SQL Server, Exchange and RDP
  • SCEP from vendor network appliances
  • Windows autoenrollment on Windows 10 and Server 2019
  • Multi-tenancy as a security boundary

Full detail is in the v1.0.0 release notes and the roadmap.
